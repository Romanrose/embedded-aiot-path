# 机构 / 维护者 / 讲义与讨论入口（首批）

分类说明：上游机制 → 培训/教材 → 板商 → 维护者与源码。

上游机制与文档
- Linux kernel 文档：`https://docs.kernel.org/`（driver model / devicetree / gpio / i2c / iio / hwmon / media / drm …）

培训/教材
- Bootlin：`https://bootlin.com/doc/training/linux-kernel/`、`https://bootlin.com/training/embedded-linux/`
- Linux Kernel Labs：`https://linux-kernel-labs.github.io/`（注意页面结构滚动）

板商/SDK 与示例文档（示例）
- LubanCat RK 系列：`https://doc.embedfire.com/linux/rk356x/driver/zh/latest/`
- 其他板型：以各自官方手册/SDK 为准，自行核板型/分支/提交

维护者与源码（查询方式）
- 目标子系统 `MAINTAINERS` 文件（内核源码根目录）；GitHub/GitLab 镜像仅作浏览  
- 邮件列表/patchwork（按子系统）  
- 提醒：人物名录以 `MAINTAINERS` 与代码提交为准，不凭印象列名人
