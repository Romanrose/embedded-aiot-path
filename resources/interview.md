# 面试 / JD 关键词与话题清单

用途：对照岗位 JD 查漏补缺。下列是 **话题 checklist**，不是题库标准答案；请用自己的项目与实验笔记作答，**不要背诵虚构数据**。

## JD 中常见关键词（勾选你目标岗出现的）

### 经典嵌入式

- [ ] C/C++、裸机、Startup、链接脚本  
- [ ] GPIO / UART / I2C / SPI / CAN  
- [ ] 中断、DMA、低功耗模式  
- [ ] FreeRTOS / RT-Thread / Zephyr  
- [ ] 设备驱动、板级调试（JTAG/SWD、逻辑分析仪）  
- [ ] 通信协议：MQTT、Modbus、私有 UART 协议  

### 系统 / SoC

- [ ] Linux 应用或驱动、设备树（Device Tree）  
- [ ] `mmap`、用户态与内核态数据路径  
- [ ] systemd / 启动时间 / rootfs 裁剪（视岗位）  
- [ ] 相机 ISP / V4L2（视觉岗常见）  

### 边缘 AI

- [ ] ONNX、模型导出与算子兼容  
- [ ] 量化（PTQ/QAT）、INT8、校准  
- [ ] TensorRT / ONNX Runtime / OpenVINO / RKNN / QNN 等（按 JD）  
- [ ] 延迟、吞吐、功耗、热设计  
- [ ] 前后处理、NMS、letterbox 等工程细节  
- [ ] CUDA / 异构调度（NVIDIA 岗）  

### 加分但需诚实

- [ ] LLM 端侧 / 蒸馏 / speculative decoding（有实践再写）  
- [ ] Agent 与边端事件联动（结合你原背景，讲清边界）  
- [ ] MLOps 轻量：版本、A/B、失败回滚  

## 话题 checklist（能讲清原理 + 一次踩坑）

### MCU vs SoC

- [ ] 实时性、内存、OS、典型外设差异  
- [ ] 产品里如何分工（MCU 管控制，SoC 管视觉/连接）  
- [ ] 你的项目里为什么选当前方案  

### 驱动与数据路径

- [ ] 轮询 vs 中断 vs DMA  
- [ ] 一次「传感器 → 内存 → 算法」的数据所有权  
- [ ] Linux 下：字符设备 / `mmap` / 零拷贝相关概念（到你学过的深度为止）  

### DMA / mmap（常被追问）

- [ ] DMA 谁发起、cache 一致性为何重要（按你平台程度回答）  
- [ ] `mmap` 映射的是什么；与 `read` 拷贝的差异  
- [ ] 与推理输入缓冲（pinned memory 等）的类比（有 GPU 经验可联系）  

### 量化与部署

- [ ] 为何要量化；精度与速度的取舍  
- [ ] 某算子不支持时你怎么处理  
- [ ] 如何测 latency（预热、同步、是否含前后处理）  

### 行为面可结合本仓

- [ ] 12 周主线如何取舍（时间不足的最小路径）  
- [ ] 一次未上板时的学习策略  
- [ ] 如何保证实验可复现（对应 `experiments/`）  

## 使用方式

1. 贴一份目标 JD，把命中的关键词勾上。  
2. 每个缺口对应到 `tracks/` 某节点或下周实验。  
3. 面试前只复习 **自己笔记里真实跑过** 的数字与日志。
