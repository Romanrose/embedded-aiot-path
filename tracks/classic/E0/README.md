# E0 · MCU / GPIO / UART / I2C 基础

**目标**：在一块 MCU 开发板上完成最小外设闭环，形成「读手册 → 配时钟/引脚 → 验证」习惯。

**前置**：开发板到手、供电与串口驱动正常。未到手时：精读目标芯片 Reference Manual 相关章节，checklist 标「理论」。

## Checklist

### 环境

- [ ] 确认板卡型号、MCU 型号、可用调试接口  
- [ ] 工具链能编译并下载 hello / blink  
- [ ] 串口能看到启动打印（波特率、线序记录在实验笔记）

### GPIO

- [ ] 输出：LED 闪烁（阻塞 delay 即可）  
- [ ] 输入：按键（上拉/下拉与消抖策略写清）  
- [ ] （可选）同一引脚复用注意点记一笔

### UART

- [ ] 发送：周期性打印计数或状态  
- [ ] 回环或 PC 回显：收什么发什么  
- [ ] 了解：阻塞 vs 中断接收（本阶段能口述差异即可）

### I2C

- [ ] 总线扫描：列出 ACK 地址（无器件则记「空扫描」）  
- [ ] 读一个传感器或 EEPROM 寄存器（器件名、地址、寄存器映射写入笔记）  
- [ ] 常见坑：上拉、地址 7/8-bit、字节序

### 习惯与安全

- [ ] 3.3 V / 5 V 电平与共地  
- [ ] 改时钟/PLL 前备份可工作配置  
- [ ] 本节点笔记路径：`experiments/YYYY-MM-DD-e0-.../`

## 验收（建议）

1. 一份接线/引脚表（Markdown 或手绘照片）。  
2. 串口日志截取（真实输出）。  
3. I2C 读数或明确的「无器件，仅扫描」说明。

## 延伸（可选，不挡 E1）

- SPI 点亮一颗屏或 Flash 读 JEDEC ID  
- 看一次逻辑分析仪波形（GPIO 或 I2C）
